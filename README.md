🚩 TryHackMe Room Reports

Welcome to my repository of write-ups, notes, and reports for various rooms on TryHackMe. This collection serves as a documentation of my learning journey through cybersecurity challenges, CTFs, and educational walkthroughs.

📖 What this project does

This repository acts as a centralized knowledge base containing detailed solutions and reports for TryHackMe rooms.

For each room, I aim to provide:

Enumeration steps: How I mapped the attack surface (Nmap, Gobuster, etc.).

Exploitation paths: The specific vulnerabilities found and how they were exploited.

Privilege Escalation: How I moved from a low-level user to root/administrator.

Key Takeaways: Concepts learned during the challenge.

The repository is organized by room difficulty (Easy, Medium, Hard, Insane) or by learning paths to make navigation intuitive.

🚀 Why this project is useful

This project serves multiple purposes for the community and myself:

Educational Resource: If you are stuck on a specific room, these reports provide a step-by-step guide to unblocking yourself.

Methodology Reference: Beyond just "getting the flag," these reports explain the why and how, helping readers understand the underlying security concepts.

Command Cheatsheet: Real-world examples of syntax for tools like Metasploit, Burp Suite, Hydra, and John the Ripper.

Progress Tracking: It documents the evolution of skills and techniques over time.

⚡ Getting Started

To use this repository, you can simply browse the files on GitHub or clone the repo to your local machine for offline reading.

Prerequisites

Basic understanding of Linux and Networking.

An account on TryHackMe (to follow along with the rooms).
